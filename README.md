# CodSoft Machine Learning Internship Portfolio

## Overview

This repository contains the projects developed during the CodSoft Machine Learning virtual internship[cite: 6]. The goal of the internship is to transform theoretical knowledge into practical expertise through project-based learning[cite: 3]. Note that successful completion requires finishing at least 3 tasks[cite: 4, 5, 8].

## Projects Included

| Task  | Project Name                | Description                                                                                                                                                                     | Directory        |
| :---- | :-------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | :--------------- |
| **1** | Movie Genre Classification  | A machine learning model that can predict the genre of a movie based on its plot summary or other textual information using techniques like TF-IDF or word embeddings[cite: 8]. | `/CODSOFT_TASK1` |
| **2** | Credit Card Fraud Detection | A model built to detect fraudulent credit card transactions using algorithms like Logistic Regression, Decision Trees, or Random Forests[cite: 9].                              | `/CODSOFT_TASK2` |
| **3** | Customer Churn Prediction   | A predictive model developed to predict customer churn for a subscription-based service using historical customer data and usage behavior[cite: 10].                            | `/CODSOFT_TASK3` |
| **4** | Spam SMS Detection          | An AI model that classifies SMS messages as spam or legitimate utilizing techniques like TF-IDF or word embeddings[cite: 11].                                                   | `/CODSOFT_TASK4` |
| **5** | Handwritten Text Generation | A character-level recurrent neural network (RNN) implemented to generate handwritten-like text based on learned patterns from a dataset of handwritten text examples[cite: 12]. | `/CODSOFT_TASK5` |

## Tech Stack

- **Language:** Python
- **Deep Learning:** TensorFlow, Keras
- **Machine Learning:** Scikit-Learn
- **Computer Vision:** OpenCV
- **Data Processing & Visualization:** Pandas, NumPy, Matplotlib, Seaborn

## Repository Structure

Each task directory is entirely self-contained, featuring:

- A fully documented Jupyter Notebook (`.ipynb`) containing the code and output.
- A task-specific `README.md` detailing the methodology and results.
- Necessary dataset mappings (e.g., `.csv` files).

_Note: Heavy raw datasets and image directories have been excluded via `.gitignore` to maintain repository performance and adhere to storage limits._
